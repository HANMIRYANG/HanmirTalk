# 제품정보 적재 스테이징 폴더 (import-products/)

한미르톡 **제품 정보**(/products) 화면에 올라갈 제품 자료를 모아두는 폴더입니다.
여기에 파일을 넣는 것만으로는 아무 일도 일어나지 않습니다 — 파일이 준비되면
Claude 에게 "제품정보 적재 진행해줘" 라고 요청하세요. 그때 파일을 읽어
**미리보기(어떤 제품이 어떤 값으로 생성되는지 목록)를 먼저 보여드리고,
확인 후에만 DB 에 넣습니다.**

> ⚠️ 자료실(파일함) 대량 적재용 `import/` 폴더와는 별개입니다.
> `import/` 는 ops/bulk-import-files.sh 가 부서 폴더 구조로 읽어가므로
> 제품 스펙 PDF 를 그쪽에 넣으면 자료실로 잘못 들어갑니다.

## 넣는 방법

- **제품 1개당 파일 1개** (PDF 권장, TXT/이미지 스캔 PDF 도 가능)
- 파일명은 제품을 식별할 수 있게:
  - `HM-EP2000_에폭시프라이머.pdf`  ← "제품코드_제품명" 형태 권장
  - `세라믹코트-500.pdf`            ← 제품명만도 가능
- 하위 폴더로 분류해도 됩니다 (폴더명 = 카테고리로 해석):
  ```
  import-products/
    방청도료/
      HM-EP2000_에폭시프라이머.pdf
    내열도료/
      세라믹코트-500.pdf
  ```

## 파일 안에 있으면 좋은 내용 (제품 페이지에 표시되는 항목)

| 항목 | 예 | 비고 |
|---|---|---|
| 제품명 | 에폭시 프라이머 HM-EP2000 | 필수 |
| 제품코드 | HM-EP2000 | 있으면 |
| 카테고리 / 하위분류 | 방청도료 / 하도 | 폴더명으로 대체 가능 |
| 제품 설명 | 한 단락 소개 | |
| 특징 | 불릿 목록 | |
| 적용 분야 | 강교량, 플랜트 외부 등 | |
| 사용 방법 | 희석비/도장방법/건조시간 등 | |
| 주의 사항 | | |
| 규격/사양 | 인장강도=520 N/mm², 비중=1.4 등 | key-value 표로 저장됨 |

- 표/문단이 섞여 있어도 됩니다 — PDF 를 읽고 알아서 위 항목으로 정리합니다.
- 값이 없는 항목은 비워두고 생성합니다 (나중에 제품 페이지에서 수정 가능).
- 원본 PDF 는 원하시면 해당 제품의 **제품 문서(카탈로그)** 로도 같이
  첨부해 드립니다 — 요청 시 말씀만 해주세요.

## 진행 절차

1. 이 폴더에 파일 배치 (진행 중에는 DB 에 아무것도 안 들어감)
2. Claude 에게 적재 요청 → 파일을 읽고 **생성될 제품 목록 미리보기** 제시
3. 미리보기 확인·수정 후 승인 → DB 반영 (제품 + 사양 + 선택 시 원본 PDF 첨부)
