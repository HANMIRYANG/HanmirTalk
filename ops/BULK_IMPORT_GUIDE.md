# 자료실(파일함) 일괄 적재 — 초보자 가이드

부서 자료를 한꺼번에 자료실에 넣는 방법입니다. 웹에서 파일을 하나씩 올릴 필요
없이, 폴더 구조로 정리해서 **한 번의 명령**으로 넣습니다.

스크립트: `ops/bulk-import-files.sh`

---

## 0. 준비 — 명령을 어디에 입력하나

서버(운영 VM)에 접속해서 명령을 입력합니다. 두 가지 방법 중 편한 것:

- **방법 A (권장)**: 평소 쓰시는 SSH 터미널(또는 Claude Code 화면)에 명령을 그대로
  붙여넣기.
- **방법 B**: Claude Code 입력창에서 맨 앞에 느낌표 `!` 를 붙이면 그 줄이 서버에서
  실행됩니다. 예) `!ls /srv/hanmir-talk`

아래 명령들은 전부 복사해서 붙여넣으면 됩니다.

---

## 1. 넣을 파일을 "부서별 폴더"로 정리

서버의 `/srv/hanmir-talk/import` 폴더를 **임시 보관함**으로 씁니다. 그 안에
**부서 이름 폴더**를 만들고, 파일을 넣습니다.

### 폴더 규칙 (중요)
- 맨 위 폴더 이름 = **부서(최상위) 폴더 이름과 똑같이**. 현재 만들어진 부서:
  - `경영지원실` `도료사업부` `영업본부` `연구소`
- 그 안에 폴더를 더 만들면 = **하위 폴더** (없으면 자동으로 생성됩니다).
- 파일은 폴더 안 아무 위치에 두면, 그 폴더로 들어갑니다.

### 예시 구조
```
/srv/hanmir-talk/import/
  경영지원실/
    2026_사규.pdf            → 경영지원실 폴더로
    인사/
      급여대장.xlsx          → 경영지원실 > 인사(자동생성) 폴더로
  연구소/
    실험데이터.xlsx          → 연구소 폴더로
```

### 파일을 서버로 옮기는 법
- **내 PC에 파일이 있으면**: 윈도우는 **WinSCP**, 맥은 **FileZilla** 같은 프로그램으로
  서버에 접속해서, 위 구조 그대로 폴더째 `/srv/hanmir-talk/import/` 안에 끌어다 놓으면
  됩니다. (드래그앤드롭이지만 폴더 통째로 한 번에 → 빠릅니다)
- **이미 서버에 파일이 있으면**: `mkdir`/`mv` 명령으로 위 구조로 옮기면 됩니다.

임시 보관함 폴더 만들기:
```bash
mkdir -p /srv/hanmir-talk/import
```

## 2. 먼저 "미리보기"로 확인 (아무것도 안 바뀜)

실제로 넣기 전에, 무엇이 어디로 들어갈지 **계획만** 보여줍니다. 안전합니다.

```bash
cd /srv/hanmir-talk
bash ops/bulk-import-files.sh
```

출력 예시:
```
  [적재예정]    경영지원실/2026_사규.pdf  →  folder=...  (12345B)
  [폴더 생성예정] 경영지원실/인사
  [적재예정]    경영지원실/인사/급여대장.xlsx
DRY-RUN 요약: 적재예정 2 · 중복skip 0 · 건너뜀 0
```

여기서 **목록이 예상과 맞는지** 확인하세요. 이상하면 1번으로 돌아가 폴더/파일을
고치고 다시 미리보기 하면 됩니다.

### 메시지 뜻
| 메시지 | 뜻 |
|---|---|
| `[적재예정]` | 이 파일이 들어갈 예정 (정상) |
| `[폴더 생성예정]` | 하위 폴더가 새로 만들어질 예정 (정상) |
| `[중복skip]` | 같은 폴더에 같은 이름이 이미 있어 건너뜀 |
| `허용되지 않은 확장자` | 지원 안 하는 파일 형식 (아래 목록 참고) |
| `부서(최상위) 폴더가 없음` | 맨 위 폴더 이름이 부서명과 안 맞음 → 이름 확인 |
| `심볼릭 링크는 적재 대상이 아닙니다` | 바로가기 말고 실제 파일을 두세요 |
| `최상위에 바로 둔 파일은…건너뜀` | 파일을 부서 폴더 안에 넣으세요 |

### 넣을 수 있는 파일 형식
`pdf` · 워드(`doc` `docx`) · 한글(`hwp` `hwpx`) · 엑셀(`xls` `xlsx` `csv`) ·
파워포인트(`ppt` `pptx`) · 이미지(`jpg` `jpeg` `png` `webp` `gif`) · 압축(`zip`)

## 3. 실제로 넣기

미리보기가 마음에 들면, 끝에 `--commit` 을 붙여 실제로 넣습니다.

```bash
cd /srv/hanmir-talk
bash ops/bulk-import-files.sh --commit
```

끝에 이런 요약이 나오면 성공:
```
완료: 적재 2 · 중복skip 0 · 건너뜀 0
```

> 💡 **처음에는 작게 테스트**: 파일 2~3개만 넣은 폴더로 먼저 `--commit` 해보고,
> 자료실에서 잘 보이는지 확인한 뒤 나머지 전체를 넣으시길 권합니다.

---

## 4. 자료실에서 확인

브라우저에서 한미르톡 → **파일함** 메뉴를 엽니다.
- "부서 폴더"에서 해당 부서 → 하위 폴더로 들어가면 넣은 파일이 보입니다.
- "전체 파일"에도 나옵니다.
- 파일을 클릭하면 다운로드됩니다.

---

## 5. 다음 배치 / 정리

- 한 번 적재한 파일은 자료실(업로드 저장소)로 **복사**된 것이라, 임시 보관함
  `/srv/hanmir-talk/import` 는 비워도 됩니다.
- 다음 묶음을 넣을 때 같은 자리(`import/`)에 다시 정리해서 2~3단계를 반복하면 됩니다.
- 같은 파일을 또 넣어도 (같은 폴더·같은 이름이면) `[중복skip]` 으로 안전하게 넘어갑니다.

임시 보관함 비우기(선택):
```bash
rm -rf /srv/hanmir-talk/import/*
```

## ⚠️ 꼭 알아둘 점 — 민감자료(급여·인사 등)

부서 폴더에 넣은 파일은 **로그인한 전 직원에게 보입니다.** 부서 "참여자"
설정은 폴더를 만들/올릴 수 있는 **쓰기 권한**일 뿐, 보는 것(읽기)은 막지 않습니다.

특정 인원만 봐야 하는 자료는 **비밀번호가 걸린 하위 폴더**에 넣어야 숨겨집니다.
비밀번호 폴더는 웹 화면(파일함)에서 해당 부서 폴더로 들어가 **+ 새 폴더** 를 만들 때
비밀번호를 지정해 만든 뒤, 그 폴더 이름으로 1번 구조를 짜서 적재하면 됩니다.

---

## 새 부서(최상위) 폴더가 필요하면

이 스크립트는 **하위 폴더만** 자동으로 만듭니다(부서 폴더는 권한 설정 때문에 제외).
새 부서 폴더는 둘 중 하나로 만드세요:
- 웹 화면(파일함) → **+ 새 부서 폴더** (관리자 권한)
- 또는 `ops/seed-default-folders.sql` 의 패턴 참고
