# 13. PWA / 모바일 정책

## 목표

직원이 앱스토어 설치 없이 모바일 홈 화면에서 한미르톡을 바로 실행할 수 있게 한다.

## 필수 요구사항

- 반응형 웹
- PWA manifest
- service worker
- 홈 화면 아이콘
- 로그인 유지
- 홈 화면 실행 시 초기 진입점은 `/dashboard` (manifest `start_url`)
- PC와 모바일 동일 계정 사용

## 로고 사용

- `assets/logo/hanmir-logo.png`를 앱 아이콘과 시작 화면에 사용한다.
- 로고가 묻히지 않도록 배경을 과도하게 복잡하게 만들지 않는다.
- 로고 주변 여백을 충분히 확보한다.

## 모바일 UX 요구사항

디자인은 Claude Design HTML 레퍼런스를 따른다.
기능 요구사항은 다음과 같다.

- 하단 주요 메뉴는 4~5개 이하로 유지
- 채팅/프로젝트/공지/파일/내정보 중심
- 버튼은 손가락으로 누르기 쉬운 크기
- 중요한 상태는 텍스트로 함께 표시
