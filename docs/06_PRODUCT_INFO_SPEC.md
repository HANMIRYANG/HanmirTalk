# 06. 제품 정보 명세

## 목적

영업팀과 내부 담당자가 제품 정보를 일관되게 확인하고 공유할 수 있도록 한다.

## 제품 정보 필드

- 제품명
- 제품 분류
- 제품 설명
- 주요 장점
- 적용 분야
- 시공/사용 방법
- 품질 관련 주의사항
- 영업 가능 상태
- 영업 제한 사유
- 담당자
- 관련 파일
- 관련 프로젝트

## 영업 가능 상태

- 불가: 외부 영업 금지
- 준비중: 자료 준비 단계
- 내부 검토 가능: 내부 설명과 검토 가능
- 제한적 영업 가능: 특정 조건 하에서 제안 가능
- 정식 영업 가능: 공식 영업 가능

## 제품 문서 유형

- 카탈로그
- 시험성적서
- 제안서
- 단가표
- 시공방법서
- FAQ
- 인증서
- 제품 이미지

## 영업 제한 사유 예시

- 시험성적서 미확정
- 단가 미확정
- 납기 기준 미확정
- 품질팀 검토 필요
- 대표 승인 필요
