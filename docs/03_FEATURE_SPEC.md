# 03. 기능 명세

## 1. 메신저

### 개인 채팅

- 직원 간 1:1 대화
- 파일/이미지 첨부
- 읽음 표시
- 메시지 검색

### 단체 채팅방

- 부서별/업무별 채팅방
- 참여자 관리
- 파일 공유
- 상단 고정 메시지

### 프로젝트방

프로젝트방은 단순 채팅방이 아니라 프로젝트와 연결된 업무 공간이다.

포함 정보:

- 대화
- 업무
- 파일
- 결정사항
- 책임자
- 진행률
- 영업 가능 상태

## 2. 공지

- 전체 직원 대상 공지 작성
- 부서별 공지 작성
- 공지 확인 버튼
- 확인자/미확인자 집계
- 공지 검색

## 3. 프로젝트 관리

프로젝트 상태:

- 준비중
- 진행중
- 검토중
- 보류
- 완료
- 중단

프로젝트 역할 (8종 — 현재 미구현, 추후 단계로 보류):

- 총괄 책임자
- 실무 책임자
- 연구 담당
- 생산 담당
- 품질 담당
- 영업 담당
- 자료 담당
- 참여자

## 7. 채팅 입력창 명령어

채팅 입력창에서 빠른 업무 호출을 지원한다. 일반 메시지 작성 흐름을 방해하지 않고, 기존 채팅 UI 디자인 위에 입력 보조 레이어(팝오버)로 동작한다. 상세 명세는 `05_MESSENGER_SPEC.md` 참고.

### `@` 멘션 / 태그

- `@사용자명` — 사용자 멘션
- `@부서명` — 부서 멘션 (현재 미구현 — 추후 단계로 보류)
- `@프로젝트코드` 또는 `@프로젝트명` — 프로젝트 참조
- `@업무코드` — 업무 참조 (예: `@T-1024`)
- `@파일명` — 파일 참조
- 동작: `@` 입력 시 검색 팝오버 표시 → 후보 선택 시 structured mention 토큰 삽입 → 전송 시 message payload의 `entities` 필드로 함께 전송
- 백엔드는 멘션 대상에게 알림 생성 가능

### `/` AI 명령어

- `/요약` — 현재 채팅방 최근 메시지 요약
- `/업무추출` — 대화에서 업무 후보 추출
- `/결정사항` — 최근 대화에서 결정사항 후보 추출
- `/공지초안` — 대화 내용 기반 공지 초안 작성
- `/회의록` — 최근 대화를 회의록 형식으로 변환
- 동작: `/` 입력 시 명령어 팝오버 → 명령 선택 → 범위(최근 20개/오늘/선택 메시지/스레드) 선택 → 결과는 **미리보기로만 표시** → 사용자가 "삽입" 또는 "전송"을 눌러야 실제 메시지로 반영
- AI 결과 메시지에는 "AI 생성 초안" 뱃지를 반드시 표시

### 권한/보안 원칙

- `@` 후보는 현재 사용자가 접근 가능한 사용자/부서/채팅방/프로젝트/파일 범위 안에서만 노출
- `/` AI 명령은 현재 사용자가 볼 수 있는 메시지/파일/프로젝트만 context로 사용
- 파일 원문 요약은 파일 접근 권한 확인 후에만 허용
- 민감 정보 보호를 위해 AI 결과는 **자동 전송 금지**
- AI가 추출한 업무/결정사항은 자동 생성되지 않고, 사용자 확정 단계 후에만 `tasks` / `decisions` 테이블에 insert

### MVP 포함 여부

- `@` 사용자 멘션: MVP 포함 가능
- `@` 부서/프로젝트/업무/파일 참조: MVP 후반 또는 MVP+
- `/` AI 명령어 전체: MVP+ 권장
- 데모 가치가 중요하면 `/요약`만 제한적으로 MVP에 포함 가능
