# 15. 개발 단계 계획

## Phase 0. 문서 및 디자인 기준 확정

- 본 docs 문서 확인
- Claude Design으로 HTML 레퍼런스 제작
- 로고 적용 기준 확인
- 기술 스택 확정

## Phase 1. 프로젝트 기본 구조

- monorepo 구조 생성
- web/server/shared 기본 세팅
- 환경변수 구조
- Docker 개발 환경
- lint/build/test 기본 명령 구성

## Phase 2. 인증/사용자/부서

- 로그인
- 사용자 관리
- 부서 관리
- 역할/권한 구조

## Phase 3. 메신저

- 방 목록
- 메시지 송수신
- WebSocket
- 파일/이미지 첨부
- 읽음 처리

## Phase 4. 공지

- 공지 작성
- 공지 확인
- 확인자/미확인자 조회

## Phase 5. 프로젝트/업무

- 프로젝트 생성/수정
- 책임자/참여자 지정
- 업무 생성/상태 관리
- 타임라인 데이터

## Phase 6. 제품 정보/영업 상태

- 제품 등록
- 제품 문서 연결
- 영업 가능 상태 관리
- 제한 사유 기록

## Phase 7. 대시보드/검색/마무리

- 전체 프로젝트 현황
- 지연 업무
- 메시지/파일/프로젝트 검색
- 모바일 PWA 점검
- Codex 검토 반영
