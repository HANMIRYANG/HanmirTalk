# 02. MVP 범위

## MVP 포함 기능

### 인증/사용자

- 직원 로그인
- 관리자 계정 생성
- 직원 계정 생성/수정/비활성화
- 부서/직급 정보 관리

### 메신저

- 1:1 채팅
- 단체 채팅방
- 프로젝트방 대화
- 이미지/파일 업로드
- 메시지 검색
- 읽음/미확인 표시
- 상단 고정 메시지
- 채팅 입력창 `@` 사용자 멘션 (사용자 검색 + structured mention 토큰 + 알림 발급)

### 공지

- 전체 공지방
- 공지 작성 권한
- 공지 확인 버튼
- 확인자/미확인자 목록

### 프로젝트

- 프로젝트 생성
- 책임자 지정
- 참여자 지정
- 상태 관리
- 진행률 관리
- 시작일/마감일 관리
- 프로젝트별 대화/파일/업무 연결

### 업무

- 업무 생성
- 담당자 지정
- 검토자 지정
- 상태 관리: 할일/진행중/검토중/완료/보류
- 우선순위
- 시작일/마감일
- 간단한 타임라인 데이터

### 제품 정보

- 제품 등록
- 제품 설명
- 영업 가능 상태
- 영업 제한 사유
- 관련 파일 연결
- 관련 프로젝트 연결

### 파일함

- 파일 업로드
- 파일 목록
- 파일명 검색
- 프로젝트/제품/채팅방별 파일 연결

### PWA/모바일

- 반응형 웹
- 홈 화면 설치 지원
- 로그인 유지
- 기본 푸시 알림 구조

## MVP 제외 기능

- 고급 간트 차트 편집기
- AI `/` 명령어 전체 세트 (`/정리`, `/업무추출`, `/결정사항`, `/공지초안`, `/회의록`) — MVP+
- 채팅 `@` 부서/프로젝트/업무/파일 참조 — MVP 후반 또는 MVP+ (사용자 멘션만 MVP에 포함)
- 전자결재
- 화상회의/음성통화
- 외부 거래처 초대
- 복잡한 자동화 워크플로우

## 제한적 MVP 후보

데모 가치가 중요할 때 한정으로 다음 한 가지만 MVP에 포함 가능:

- `/요약` — 현재 채팅방 최근 메시지 요약 (결과는 미리보기로만 표시, 자동 전송 금지)

LLM provider 연동, rate limit, 감사 로그 요구사항 충족 시에만 활성화.

## MVP에서 간트 차트 처리

초기에는 고급 간트 차트 라이브러리를 완전 구현하지 않고, 업무의 `start_date`, `due_date`, `progress`, `status` 데이터를 먼저 안정적으로 저장한다. 이후 이 데이터를 바탕으로 간트 차트를 시각화한다.

## 채팅 입력창 명령어 — MVP 분류

상세 명세는 `03_FEATURE_SPEC.md`와 `05_MESSENGER_SPEC.md` 참고.

| 기능 | MVP 포함 | 비고 |
| --- | --- | --- |
| `@` 사용자 멘션 | ✅ 포함 | 멘션 시 알림 발급 포함 |
| `@` 부서 참조 | ❌ MVP 후반 또는 MVP+ | |
| `@` 프로젝트 참조 | ❌ MVP 후반 또는 MVP+ | |
| `@` 업무 참조 | ❌ MVP 후반 또는 MVP+ | |
| `@` 파일 참조 | ❌ MVP 후반 또는 MVP+ | |
| `/요약` | △ 제한적 MVP | 데모 우선시에만 |
| `/정리` `/업무추출` `/결정사항` | ❌ MVP+ | |
| `/공지초안` `/회의록` | ❌ MVP+ | |

AI 결과는 어떤 경우에도 자동 전송하지 않으며, 사용자가 접근 가능한 메시지/파일/프로젝트만 context로 사용한다.
