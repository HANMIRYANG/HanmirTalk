# 04. 프로젝트 관리 명세

## 목적

제품 개발, 시험, 인증, 영업 준비, 납품 준비, 조달 등록 등 회사의 중요한 업무를 프로젝트 단위로 관리한다.

## 프로젝트 기본 정보

- 프로젝트명
- 설명
- 상태
- 중요도
- 시작일
- 목표 종료일
- 실제 종료일
- 총괄 책임자
- 실무 책임자
- 참여 부서
- 관련 제품
- 관련 거래처
- 진행률
- 영업 가능 상태

## 프로젝트 진행률 산정

MVP에서는 수동 입력을 허용한다.

추후 자동 산정 방식:

- 완료 업무 수 / 전체 업무 수
- 업무별 가중치 반영
- 지연 업무 감점

## 프로젝트 위험 표시

프로젝트에 다음 상태가 있으면 위험으로 표시한다.

- 마감일 초과 업무 존재
- 영업 가능 상태가 `불가` 또는 `준비중`
- 책임자 미지정
- 필수 파일 미첨부
- 검토중 상태가 오래 지속됨

## 간트 차트 확장 방향

MVP 데이터 구조는 간트 차트 확장을 전제로 한다.

필수 업무 필드:

- start_date
- due_date
- progress
- status
- dependency_task_id optional

추후 간트 차트 기능:

- 업무 막대 표시
- 지연 업무 빨간 표시
- 담당자별 필터
- 프로젝트별 월간 보기
- 업무 의존관계 표시
