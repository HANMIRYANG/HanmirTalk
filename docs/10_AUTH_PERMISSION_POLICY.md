# 10. 인증 및 권한 정책

## 로그인 방식

MVP 권장 방식:

- 관리자 계정이 직원 계정을 생성한다.
- 직원은 휴대폰번호 또는 이메일과 비밀번호로 로그인한다.
- 첫 로그인 후 비밀번호 변경을 요구한다.

## 역할

- super_admin: 시스템 전체 관리자
- admin: 회사 관리자
- manager: 팀장/책임자
- project_owner: 프로젝트 책임자
- member: 일반 직원

## 권한 원칙

- 일반 직원은 자신이 참여한 방과 프로젝트만 볼 수 있다.
- 공지 작성은 관리자/지정 권한자만 가능하다.
- 프로젝트 생성은 관리자/책임자급만 가능하다.
- 프로젝트 책임자는 프로젝트 정보와 업무를 수정할 수 있다.
- 파일 삭제는 업로드자 또는 관리자만 가능하다.
- 결정사항 수정/삭제는 관리자 또는 결정자만 가능하다.

## 보안 원칙

- 비밀번호는 bcrypt 또는 argon2로 해시 처리한다.
- JWT access token + refresh token 구조를 사용한다.
- 파일 다운로드 시 권한을 확인한다.
- 모든 삭제는 가능하면 soft delete로 처리한다.
- 관리자 작업은 감사 로그를 남긴다.
