# 01. PRD

## 목표

한미르주식회사 직원들이 PC와 모바일에서 쉽게 사용할 수 있는 사내 업무 메신저와 프로젝트 관리 시스템을 구축한다.

## 대상 사용자

- 대표/임원: 전체 프로젝트 현황, 지연 업무, 책임자, 결정사항 확인
- 팀장/책임자: 프로젝트 생성, 업무 배정, 진행 상황 관리
- 영업 담당: 제품 정보, 영업 가능 상태, 제안 자료 확인
- 연구/생산/품질 담당: 제품 개발, 시험성적서, 품질 이슈, 생산 가능 여부 공유
- 일반 직원: 공지 확인, 채팅, 파일 공유, 업무 확인

## 서비스 언어

- 전체 서비스 UI, 메뉴, 알림, 오류 메시지는 한국어로 제공한다.
- 내부 코드와 API 명세는 영어 네이밍을 사용할 수 있다.

## 핵심 사용자 경험

- 앱 실행 후 모바일은 채팅/업무 목록으로 바로 진입한다.
- 40대 이상 직원도 별도 교육 없이 사용할 수 있어야 한다.
- 메뉴명은 `채팅`, `프로젝트`, `업무`, `공지`, `파일함`, `제품정보`, `관리자`처럼 쉬운 한국어를 사용한다.
- Slack의 기능 구조를 참고하되 사용자가 Slack 용어를 몰라도 사용할 수 있어야 한다.

## 성공 기준

- 직원들이 카카오톡처럼 자연스럽게 메시지를 주고받는다.
- 프로젝트마다 책임자와 진행률을 확인할 수 있다.
- 영업 가능/불가 사유가 기록되고 공유된다.
- 공지 확인 여부를 관리자가 확인할 수 있다.
- 제품별 제안서, 시험성적서, 카탈로그를 쉽게 찾을 수 있다.
