# 17. Codex 검토 체크리스트

## 역할

Codex는 Claude Code가 구현한 결과물을 검증하고 디버깅 계획을 제시한다.

## 검토 기준

### 요구사항 검토

- PRD 요구사항이 반영되었는가?
- MVP 범위를 초과한 임의 기능이 추가되지 않았는가?
- 프로젝트/업무/제품/공지/메신저 구조가 문서와 일치하는가?

### UI 레퍼런스 검토

- 구현 결과가 `design-reference/html/`의 HTML 레퍼런스를 따르는가?
- Claude Code가 임의로 UI를 변경하지 않았는가?
- 서비스 텍스트가 한국어로 되어 있는가?
- 톤앤매너가 깔끔한 업무용 스타일인가?
- 한미르 로고가 적절히 사용되었고 묻히지 않는가?

### 기술 검토

- 빌드가 성공하는가?
- 타입 오류가 없는가?
- API가 명세와 일치하는가?
- DB 스키마가 기능 요구사항을 충족하는가?
- WebSocket 구조가 적절한가?
- 파일 업로드 보안이 고려되었는가?
- 권한 처리가 안전한가?

### 모바일/PWA 검토

- 모바일 반응형이 정상인가?
- PWA manifest가 있는가?
- 홈 화면 설치가 가능한가?
- 로그인 유지가 동작하는가?
