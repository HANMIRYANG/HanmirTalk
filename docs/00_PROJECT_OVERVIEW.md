# 00. 프로젝트 개요

## 프로젝트명

한미르톡 Hanmir Talk

## 목적

한미르주식회사의 내부 커뮤니케이션, 프로젝트 관리, 제품 정보 공유, 영업 가능 상태 관리, 책임자 지정, 진행 상황 추적을 하나의 업무 허브에서 처리한다.

## 제품 정의

한미르톡은 단순 사내 메신저가 아니다.

> 카카오톡처럼 쉽게 쓰는 메신저를 기반으로, Slack처럼 프로젝트·업무·파일·공지·책임자·진행률을 관리하는 한미르 전용 업무 허브이다.

## 주요 문제

- 제품 개발 정보가 직원과 영업팀에게 충분히 공유되지 않음
- 누가 책임자인지 명확하지 않음
- 프로젝트 진행률과 지연 사유가 보이지 않음
- 영업 가능/불가 기준이 개인 대화 속에 묻힘
- 결정사항이 기록되지 않아 나중에 책임 소재가 불명확함
- 파일, 시험성적서, 제안서, 단가표가 흩어짐

## 해결 방향

- 모든 대화는 프로젝트, 업무, 제품 정보, 결정사항으로 연결될 수 있어야 한다.
- 프로젝트에는 책임자, 담당자, 진행률, 일정, 영업 가능 상태가 반드시 표시되어야 한다.
- 공지에는 확인 기능이 있어야 한다.
- 제품 정보에는 영업팀이 바로 참고할 수 있는 자료와 주의사항이 있어야 한다.
- PC와 모바일에서 같은 계정으로 이어서 사용할 수 있어야 한다.
