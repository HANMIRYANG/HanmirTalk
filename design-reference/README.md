# Design Reference

이 폴더에는 Claude Design이 생성한 HTML 레퍼런스를 넣습니다.

Claude Code는 이 HTML 파일들을 기준으로 UI를 구현해야 합니다.

## 예상 파일

- login.html
- chat-list.html
- chat-room.html
- project-detail.html
- project-tasks.html
- project-gantt.html
- product-detail.html
- file-library.html
- admin.html
- mobile-reference.html

## 원칙

- HTML 레퍼런스는 디자인 기준입니다.
- Claude Code는 레퍼런스를 임의로 재해석하지 않습니다.
- 기능 구현을 위해 컴포넌트화는 가능하지만 시각적 결과는 유지해야 합니다.
